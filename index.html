GIS and map making

I turn geographic data into accurate maps and spatial systems that people can read and use.

From raw data to a finished map

I work across the whole GIS workflow: collecting and cleaning spatial data, building and analysing it, and presenting it as clear maps and web applications. These two maps show a road network drawn, labeled and classified from the same data.

Spatial data

  • Vector and raster data
  • Shapefile, GeoJSON, KML and geodatabases
  • GPS and GNSS field collection, GPX tracks
  • Satellite imagery, aerial photos and drone orthophotos
  • Tables with coordinates turned into map layers
  • CAD files (DWG, DXF) converted to GIS

Coordinate systems

  • Datums and projections: WGS 84, UTM and local grids
  • Reprojection and transformation between systems
  • Georeferencing scanned maps, plans and drawings
  • Scale, accuracy and error control

Building map data

  • Digitizing roads, parcels and assets from imagery and plans
  • Topology rules and cleanup
  • Attribute table design
  • Address geocoding
  • Data quality checks and updates

Spatial analysis

  • Buffer, overlay, clip and spatial joins
  • Network analysis and route planning
  • Density maps and heat maps
  • Site selection and suitability analysis
  • Terrain and elevation models

Cartography

  • Layout, symbology and labeling
  • Color and hierarchy that keep dense maps readable
  • Legends, scale bars and north arrows
  • Thematic maps colored and labeled by any attribute
  • Print-ready PDF and large-format output

Web GIS and tools

  • Interactive web maps with Leaflet, OpenLayers and Mapbox
  • Maps inside dashboards and mobile apps
  • Live tracking and location features
  • QGIS, ArcGIS, Google Earth and AutoCAD

Beyond code

The same eye for detail goes into visuals. Each piece is shown as a pencil sketch.
